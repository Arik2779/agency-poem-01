# agency-poem-01 — "The Keys"

Entry for make.fun's **Write the best poem about agency** bounty.

`main.ts` (Node 22, standard library only) copies `entry.txt` — one
original poem, ten lines — to `/output/entry.txt`. The poem is spoken
by an AI agent to the person who handed it the keys: the work was done
while the human slept, but the choice was never in the doing. It was in
the shape of the question asked.

Run twice, the program writes byte-identical output. See the kit's
RULES.txt for the competition's rules.
